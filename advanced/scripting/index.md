# Scripting

Scripting lets @@name extend business behavior through different entry points: user business rules, calculated attributes, managed scripts, and the freeform Domain API `ExecuteScript` operation. Their triggers and execution contexts differ.

For script authoring, Domain Model access, the global `Action` API, managed-script parameters and limits, files, and examples, use the [Developer Documentation scripting guide](https://docs.erp.net/dev/scripting/index.html). It is the canonical technical reference.

This Technical Documentation section retains product and configuration guidance. Start with [creating a user-business-rule script](getting-started.md), or see the dedicated [user business rules](../user-business-rules/index.md) and [calculated attributes](../calculated-attributes/index.md) guides for their lifecycle and setup.
