# Scripting features

- Full use of the scripting language syntax and all language constructs.

- Blazing fast execution with minimal footprint.

- Access to the context supplied by the hosting feature: for example, `subject` in an entity-based rule or calculated attribute, or declared `args` in a managed script.

- Access the @@name Domain Model through exposed repositories, subject to the current transaction's permissions.

- Global `Action` object for quick execution of common functions and host-specific operations.

- Access to current session data.

- Execution through configured scripting APIs and runtime limits.

The [Developer Documentation scripting guide](https://docs.erp.net/dev/scripting/index.html) explains the supported APIs, execution limits, security, and examples.
