# Advanced Domain scripting examples

The maintained examples and filter reference are in the Developer Documentation: [Shared patterns](https://docs.erp.net/dev/scripting/examples/shared-patterns.html), [Examples by feature](https://docs.erp.net/dev/scripting/examples/index.html), and [Query Domain entities](https://docs.erp.net/dev/scripting/domain-model/queries.html).

Complete scripts are organized by feature so a business-rule-specific `subject` is not mistaken for a managed-script global.
