# Advanced Domain scripting examples

The maintained examples and filter reference are in the Developer Documentation: [Script examples](https://docs.erp.net/dev/scripting/examples.html) and [Query Domain entities](https://docs.erp.net/dev/scripting/domain-model/queries.html).

Examples are organized by script entry point so a business-rule-specific `subject` is not mistaken for a managed-script global.
