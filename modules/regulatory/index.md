# Regulatory

The Regulatory module group contains functionality for preparing statutory reports and data submissions required by public authorities.

## Structure

| Module | Description |
| :--- | :--- |
| **[Excise](https://docs.erp.net/tech/modules/regulatory/excise/index.html)** | Manages compliance for excise tax on regulated products, including tax warehouses, excise transactions, stamp operations, and declarations. |
| **[Intrastat](https://docs.erp.net/tech/modules/regulatory/intrastat/index.html)** | Manages statistical reporting for goods movement, including the creation of Intrastat declarations and the maintenance of commodity codes. |
| **[SAF-T](https://docs.erp.net/tech/modules/regulatory/saft/index.html)** | Manages the preparation and export of Standard Audit File for Tax (SAF-T) reports, including official tax nomenclatures and country-specific mappings. |
| **[VAT](https://docs.erp.net/tech/modules/regulatory/VAT/index.html)** | Provides functionality related to Value Added Tax compliance, including VAT declarations and sales and purchase entries. |
